# dent-plus

Public website for **Dent Plus Multi Speciality Dental & Family Clinic**, Ashok Nagar 3rd Lane, Lakshmipuram, Guntur 522007 — dental care led by prosthodontists and implantologists, with family medicine, children's health and eye care under one roof.

Runs on **ClinicFlow247 Enterprise (white-label)**: live booking by department or doctor, SMS-verified appointments, and the clinic-branded ClinicFlow247 portal for patients and staff.

- Next.js 14 (App Router), TypeScript, Tailwind, zod-validated content in `/content`
- `npm run dev` · `npm run check` (lint, types, tests, WCAG contrast, build, originality)
- Project guide, rules and deployments: [`CLAUDE.md`](CLAUDE.md) · open items: [`PENDING_ITEMS.md`](PENDING_ITEMS.md) · demo: [`docs/DEMO_RUNBOOK.md`](docs/DEMO_RUNBOOK.md)

Content marked *Draft* on staging is awaiting the clinic's confirmation; nothing is invented. Patient faces in clinic photos are blurred.
